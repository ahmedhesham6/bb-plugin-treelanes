# Security policy

## Supported versions

We fix security problems in the latest version of Treelanes.

## Report a problem

Report a security problem in private: open the **Security** tab of this
repository, then select **Report a vulnerability**. Tell us:

- the Treelanes and bb versions,
- the steps that show the problem,
- what an attacker can do with it.

We try to reply within seven days. We tell you when we fix the problem. If you
agree, we credit you in the release notes.

Treelanes runs inside bb as full-trust plugin code, so it can read all local
bb data.
