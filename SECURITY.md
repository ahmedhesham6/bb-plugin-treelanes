# Security policy

## Supported versions

We fix security problems in the latest version of Treelanes.

## Report a problem

Do not open a public issue for a security problem.

Report it in private: open the **Security** tab of this repository, then
select **Report a vulnerability**. Tell us:

- the Treelanes and bb versions,
- the steps that show the problem,
- what an attacker can do with it.

We try to reply within seven days. We tell you when we fix the problem. If you
agree, we credit you in the release notes.

Treelanes runs inside bb as full-trust plugin code. It can read local bb data.
Read the bb plugin documentation before you install a plugin from a source
that you do not trust.
